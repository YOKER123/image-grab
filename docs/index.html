核心功能

为批量收集电商图片而生的完整工具链。

一键提取

自动扫描页面所有商品图，兼容 data-src、srcset、背景图等懒加载方式。

智能过滤

自动排除图标、logo、1×1 占位图和小于 100×100 的小图，结果干净。

集中预览

新页面响应式网格展示所有图片，附尺寸信息与序号，一目了然。

自由勾选

全选、反选、清空随心操作，实时统计已选数量，按需下载。

统一 PNG

jpg / webp 自动经 canvas 转换为 PNG，素材格式整齐划一。

批量下载

一键保存到本地下载目录，文件名自动编号（商品图_001.png），带进度反馈。

安装步骤

四步完成，全程不到一分钟。

  1. 1

    下载插件压缩包

    从本页底部「下载插件」获取压缩包，解压到本地任意文件夹。

  2. 2

    打开扩展管理页

    打开 Chrome，地址栏输入 chrome://extensions 回车。

  3. 3

    开启开发者模式

    打开页面右上角的「开发者模式」开关。

  4. 4

    加载插件

    点击「加载已解压的扩展程序」，选择解压后的文件夹即可。
